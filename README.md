# Финик

«Финик» — бесплатный учебный прототип для детей 7–11 лет. Ребёнок заботится о виртуальной сове, получает только игровые монеты, распределяет их между нужным, желаемым и копилкой, а затем видит результат своих решений. В приложении нет реальных платежей и рекламы.

Техническое задание: `6. Департамент финансов города Москвы.pdf` (2026). Подробная матрица требований, правила экономики, карта контента и протокол проверки находятся в [техническом отчёте](docs/technical_report.md). PDF-версия отчёта: [Finik_technical_report.pdf](output/pdf/Finik_technical_report.pdf). [Презентация](output/presentation/Finik_pitch_2026.pptx) содержит 10 слайдов для защиты.

## Быстрый запуск

Требуются macOS, Linux или Windows с Android SDK Platform 37, Build Tools 37.0.0, JDK 17 или новее (локальная проверка выполнена с JDK 25), доступ к Google Maven/Maven Central и Gradle Wrapper 9.7.1. Android Studio может установить SDK автоматически. Минимальная версия устройства — Android 8.0 (API 26), экран от 360 dp в портретной ориентации.

```sh
./gradlew :app:assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
adb shell am start -n dev.bober.finik/.MainActivity
```

Для обязательного игрового сценария сеть и учётная запись не нужны. Адрес API по умолчанию пустой. Отладочную сборку можно подключить к HTTPS-серверу через `FINIK_DEBUG_API_BASE_URL`, релизную — через `FINIK_API_BASE_URL` (только HTTPS). Сетевые дополнения включаются отдельно взрослым в приложении; локальные деньги, покупки, задания и прогресс остаются источником истины.

## Сборка подписанного релиза

Готовый конкурсный APK: [Finik-contest-release.apk](output/apk/Finik-contest-release.apk). Он подписан локальным ключом вне репозитория; `apksigner` подтвердил подпись APK Signature Scheme v2. SHA-256: `44c3dcf9664d47dd75d581bef61fe17b797155c5f2c23d3dbc0cb9c44775d75d`. Ключ и пароли не входят в исходники. Чтобы воспроизвести сборку с собственным keystore, задайте четыре переменные ниже; без них Gradle собирает неподписанный `app-release-unsigned.apk`.

```sh
export FINIK_KEYSTORE_PATH=/absolute/path/outside/repository/finik-release.jks
export FINIK_KEYSTORE_PASSWORD='your-store-password'
export FINIK_KEY_ALIAS=finik
export FINIK_KEY_PASSWORD='your-key-password'
# Необязательно: HTTPS-сервис только для дополнительных материалов.
export FINIK_API_BASE_URL=https://your-domain.example/
./gradlew :app:assembleRelease
```

Проверьте `app/build/outputs/apk/release/app-release.apk` с помощью `apksigner verify --verbose --print-certs`, затем установите его командой `adb install -r ...`. Ключ храните вне репозитория и вне материалов для экспертов. `FINIK_API_BASE_URL` можно не задавать: локальная игра работает офлайн. Для релизного номера используются `applicationId=dev.bober.finik`, `versionCode=1`, `versionName=1.0`; перед публикацией проверьте уникальность имени пакета в кабинете RuStore и при следующей публикации повысьте версию. Исходный код в релизе не обфусцируется.

Черновик карточки RuStore, иконка 512×512 и пять экранов — в [docs/rustore](docs/rustore/STORE_LISTING.md). До финальной отправки нужны проверка подписанной сборки на физическом устройстве и резервное видео живой демонстрации до 3 минут.

## Как пройти демонстрационный сценарий

1. Запустите приложение и создайте сову: выберите цвет, аксессуар и игровое имя. Реальное имя, телефон и адрес почты не нужны.
2. На главном экране посмотрите стартовые монеты, цель и активное задание. Подсказка открывается кнопкой `?`.
3. В «Плане» распределите доход на еду, воду, игры и копилку. Можно использовать совет 40/30/10/20; подтвердите план.
4. В «Заданиях» решите ситуацию. Ошибочный ответ даёт объяснение и повторную попытку; верный начисляет монеты с указанным источником.
5. В «Лавке» купите нужное и желаемое, затем попробуйте товар, на который не хватает монет. Перед покупкой есть цена, тип и эффект; списание требует подтверждения.
6. В «Мечте» выберите цель и пополните копилку. Посмотрите стоимость, накопленное и остаток; снятие средств требует отдельного подтверждения с предварительным прогнозом.
7. На главном экране закройте период, откройте фактический отчёт, затем повторите цикл до пяти периодов. Закрытие вручную доступно после подтверждения плана, календарного ожидания нет.
8. Закройте приложение принудительно, откройте снова и проверьте сохранение. Откройте профиль, пройдите арифметический барьер взрослого, затем выберите «Удалить профиль и данные» и подтвердите действие.

Не сбрасывайте профиль с нужным вам прогрессом. Подробные шаги и ожидаемые результаты: [docs/DEMO_AND_TESTS.md](docs/DEMO_AND_TESTS.md).

## Состав репозитория

| Путь | Назначение |
| --- | --- |
| `app` | Activity, навигационный граф, конфигурация вариантов сборки и подписи |
| `core/model` | Модели профиля, бюджета, транзакций, цели и питомца |
| `core/data` | `GameEngine`, локальный репозиторий, каталог заданий, сериализация состояния |
| `core/database` | Room, одна запись с JSON-снимком игрового профиля |
| `core/network` | Ktor-клиент для необязательного HTTPS-контента и взрослых функций |
| `core/designsystem` | Общие компоненты, иконки, цвета, шрифты и настройки доступности |
| `core/pet` | 3D-совa, материалы и анимации SceneView |
| `feature/*` | Онбординг, главный экран, план, задания, лавка, мечта, рост, отчёт и взрослый раздел |
| `docs` | Технический отчёт, тестовый сценарий, карточка RuStore и презентация |

Зависимость направлена от `app` через `feature/*` к `core/*`. UI читает `GameSnapshot` через `FinikViewModel`; `GameEngine` рассчитывает локальные действия чистыми функциями. `FinikRepository` сохраняет снимок в Room; по запросу взрослого HTTPS-сервис может дополнить словарь, слово дня и событие. Новые встроенные задания добавляются в `core/data/content/ContentCatalog.kt` без изменения правил экономики. Для загрузки заданий с сервера нужны отдельные контракт API, backend и проверка совместимости.

## Данные и безопасность

Локально хранятся игровое имя совы, вид, план/факт бюджета, транзакции, накопления, выбранная цель, состояние и рост питомца, задания и настройки. При включении сетевых дополнений приложение создаёт случайный идентификатор установки и может передать его HTTPS-сервису вместе с запросами дополнительных материалов. Реальные имя, телефон, почта, платёжные данные, камера, микрофон, геолокация и контакты не запрашиваются. Единственное разрешение Android — `INTERNET`, нужное для добровольных сетевых материалов. Android Backup отключён, чтобы локальный профиль не копировался автоматически в облако ОС. Взрослый может удалить локальный профиль через защищённый раздел; при сетевом режиме удаление данных сервера требует отдельной проверки с работающим backend.

Свободный AI-чат доступен только в разделе взрослого. Для конкурсного офлайн-сценария он не нужен. Сетевая часть на момент этой поставки представлена клиентом; серверный исходный код, адрес развертывания, Docker Compose и проверенная OpenAPI-спецификация в репозитории отсутствуют. Без них нельзя подтверждать совместимость или локальный запуск backend. Релиз по умолчанию использует только локальный игровой цикл.

## Проверка

```sh
./gradlew :core:data:testDebugUnitTest :core:network:testDebugUnitTest :app:assembleDebug
./gradlew :app:assembleRelease
```

Критичная экономика проверяется юнит-тестами. На AVD Android 36.1 (2.5 ГБ RAM) после force-stop сохранились профиль, 30 свободных монет и план 16/12/9/8. При 360 dp видны сова, баланс, цель и задание. Измерения `adb shell am start -W` до появления Activity на этом перегруженном эмуляторе колебались от 1,6 до 28,5 с; загрузочный экран иногда оставался дольше. На предыдущей debug сборке возник ANR при первом запуске после установки. Соответствие требованию пуска за 5 с и отклика до 1 с на физическом Android 8.0+ с 3 ГБ RAM не подтверждено. Протокол и ограничения — в [docs/DEMO_AND_TESTS.md](docs/DEMO_AND_TESTS.md).

## Права на материалы

Nunito и Unbounded распространяются по SIL Open Font License 1.1; тексты лицензий в `core/designsystem/fonts`. Пользователь подтвердил права на `core/pet/src/main/assets/models/owl/finny.glb` и шесть текстур совы для включения в прототип. Шесть прозрачных 2D-вариантов совы для узкого экрана созданы из уже включённого портрета совы, включая пять отредактированных цветовых вариантов. Векторная иконка приложения создана в исходниках проекта. Основные программные зависимости и их версии приведены в `gradle/libs.versions.toml`; перечень и ссылки на лицензии — в техническом отчёте. При передаче прав третьим лицам отдельно приложите исходное подтверждение прав на модель, текстуры и исходный портрет.
