# Финик

«Финик» — бесплатный учебный прототип для детей 7–11 лет. Ребёнок заботится о виртуальной сове, получает только игровые монеты, распределяет их между нужным, желаемым и копилкой, а затем видит результат своих решений. В приложении нет реальных платежей и рекламы.

Актуальные согласованные правила интеграции с сервером: [integration-spec.md](docs/integration-spec.md). Результаты проверки: [integration-validation.md](docs/integration-validation.md). Технический отчёт и презентация ниже описывают предыдущую локальную версию.

Техническое задание: `6. Департамент финансов города Москвы.pdf` (2026). Подробная матрица требований, правила экономики, карта контента и протокол проверки находятся в [техническом отчёте](docs/technical_report.md). PDF-версия отчёта: [Finik_technical_report.pdf](output/pdf/Finik_technical_report.pdf). [Презентация](output/presentation/Finik_pitch_2026.pptx) содержит 10 слайдов для защиты.

## Быстрый запуск

Требуются macOS, Linux или Windows с Android SDK Platform 37, Build Tools 37.0.0, JDK 17 или новее (локальная проверка выполнена с JDK 25), доступ к Google Maven/Maven Central и Gradle Wrapper 9.7.1. Android Studio может установить SDK автоматически. Минимальная версия устройства — Android 8.0 (API 26), экран от 360 dp в портретной ориентации.

```sh
./gradlew :app:assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
adb shell am start -n dev.bober.finik/.MainActivity
```

Игровое состояние и все изменения хранятся на сервере `finik-backend`. Перед запуском приложения запустите API с PostgreSQL, примените миграции и загрузите справочники. В debug адрес можно изменить прямо в приложении: **«Адрес сервера»** на экране знакомства или в профиле. Введите IP компьютера и нажмите **«Проверить и подключиться»**; адрес сохранится без пересборки APK. Для эмулятора кнопка **«Эмулятор»** подставляет `http://10.0.2.2:8000/`. Начальный адрес задаётся в `app/build.gradle.kts` или переменной `FINIK_DEBUG_API_BASE_URL` перед сборкой; сохранённый адрес имеет приоритет. Релиз использует `FINIK_API_BASE_URL` и разрешает только HTTPS.

Пошаговая инструкция для экспертов: [подключение телефона к серверу](docs/expert-setup.md).

Без сети можно просматривать последнее загруженное состояние. Покупки, уход, задания и другие изменения требуют связи с API. Приложение автоматически авторизует установку; пароль, телефон и почта не запрашиваются. Room хранит кэш, а сервер рассчитывает результаты действий.

Для локальной среды этого проекта PostgreSQL из Postgres.app работает на порту **5433**, база — `finik`. API запускается конфигурацией **Finik API** в PyCharm или командой из каталога backend:

```sh
uv run alembic upgrade head
PYTHONPATH=src uv run python -m infrastructure.content.seed
uv run uvicorn main:app --app-dir src --reload --host 127.0.0.1 --port 8000
```

Переменные backend задаются в его `.env`; клиенту не нужны пароль PostgreSQL или ключи ИИ.

## Сборка подписанного релиза

Архивный конкурсный APK предыдущей локальной версии (новую интеграцию не содержит): [Finik-contest-release.apk](output/apk/Finik-contest-release.apk). Он подписан локальным ключом вне репозитория; `apksigner` подтвердил подпись APK Signature Scheme v2. SHA-256: `44c3dcf9664d47dd75d581bef61fe17b797155c5f2c23d3dbc0cb9c44775d75d`. Ключ и пароли не входят в исходники. Чтобы воспроизвести сборку с собственным keystore, задайте четыре переменные ниже; без них Gradle собирает неподписанный `app-release-unsigned.apk`.

```sh
export FINIK_KEYSTORE_PATH=/absolute/path/outside/repository/finik-release.jks
export FINIK_KEYSTORE_PASSWORD='your-store-password'
export FINIK_KEY_ALIAS=finik
export FINIK_KEY_PASSWORD='your-key-password'
# HTTPS-адрес игрового сервера для релизной сборки.
export FINIK_API_BASE_URL=https://your-domain.example/
./gradlew :app:assembleRelease
```

Проверьте `app/build/outputs/apk/release/app-release.apk` с помощью `apksigner verify --verbose --print-certs`, затем установите его командой `adb install -r ...`. Ключ храните вне репозитория и вне материалов для экспертов. `FINIK_API_BASE_URL` необходимо задать для работающей релизной интеграции. Для релизного номера используются `applicationId=dev.bober.finik`, `versionCode=1`, `versionName=1.0`; перед публикацией проверьте уникальность имени пакета в кабинете RuStore и при следующей публикации повысьте версию. Исходный код в релизе не обфусцируется.

Черновик карточки RuStore, иконка 512×512 и пять экранов — в [docs/rustore](docs/rustore/STORE_LISTING.md). До финальной отправки нужны проверка подписанной сборки на физическом устройстве и резервное видео живой демонстрации до 3 минут.

## Обычная игра и демо

Обычная неделя идёт с понедельника до понедельника по часовому поясу игрока. Время определяет сервер. Ручного завершения дня или недели нет; при возвращении после отсутствия сервер обрабатывает прошедшее время, но доход за пропущенные недели не выдаёт.

Демо открыто без кода и работает в отдельном профиле. Эксперт выбирает новую игру или подготовленный профиль. Только в демо доступны переход на следующий день и завершение недели.

Проверочный сценарий:

1. Создать сову или выбрать подготовленное демо.
2. Распределить часть свободных монет и подтвердить план. Добавить оставшиеся монеты в подтверждённый план.
3. Выполнить уход, купить товар, внести деньги в цель из «Копилки», снять часть в «Развлечения».
4. Переключить цель и проверить, что у каждой сохранён отдельный баланс.
5. Пройти урок с выбором/числовым ответом, получить награду, открыть экспедицию и повторение темы.
6. Выбрать вариант ежедневного события, проверить обновление серверного состояния.
7. В демо перейти к следующей неделе и проверить перенос остатков и 5% от остатка «Копилки».
8. Перезапустить приложение, проверить восстановление. Без сети доступен просмотр кэша; изменения не выполняются.

## Состав репозитория

| Путь | Назначение |
| --- | --- |
| `app` | Activity, навигационный граф, конфигурация вариантов сборки и подписи |
| `core/model` | Модели профиля, бюджета, транзакций, цели и питомца |
| `core/data` | Серверный репозиторий, сессии обычной игры/демо, преобразование ответов и кэш |
| `core/database` | Room, отдельные JSON-кэши обычного и демонстрационного профиля |
| `core/network` | Ktor-клиент игрового API и его DTO |
| `core/designsystem` | Общие компоненты, иконки, цвета, шрифты и настройки доступности |
| `core/pet` | 3D-совa, материалы и анимации SceneView |
| `feature/*` | Онбординг, главный экран, план, задания, лавка, мечта, рост, отчёт и взрослый раздел |
| `docs` | Технический отчёт, тестовый сценарий, карточка RuStore и презентация |

Зависимость направлена от `app` через `feature/*` к `core/*`. UI читает `GameSnapshot` через `FinikViewModel`. `FinikRepository` отправляет действия API и обновляет состояние по ответу сервера. Локальный `GameEngine` не является источником игровых денег и наград. Каталоги товаров, целей и заданий загружаются с сервера.

## Данные и подключение

На сервер передаются случайный идентификатор установки, игровое имя совы, её внешность, часовой пояс и игровые действия. Основная база — PostgreSQL; на устройстве сохраняются сессия и кэш последнего состояния. Обычный и демонстрационный профили разделены. Авторизация по устройству не предоставляет вход по почте и перенос аккаунта на другой телефон.

Реальные имя, телефон, почта, платёжные данные, камера, микрофон, геолокация и контакты не запрашиваются. Android Backup отключён. Сброс профиля выполняется через API; он требует подключения.

ИИ обслуживается backend через GigaChat/DeepSeek; ключи остаются на сервере. При недоступности провайдера сервер использует подготовленные тексты. Родительский бонус требует PIN, настроенного на backend.

## Проверка

```sh
./gradlew :core:data:testDebugUnitTest :core:network:testDebugUnitTest :app:assembleDebug
./gradlew :app:assembleRelease
```

Экономика и календарь проверяются в репозитории backend. Его API-тесты очищают тестовую схему: используйте отдельную базу через `FINIK_DATABASE_URL`, никогда основную `finik`. В этом Android-репозитории проверки сетевого контракта и преобразования состояния дополняют сборку приложения. Исторические показатели старого APK в `docs/DEMO_AND_TESTS.md` не подтверждают новую версию.

## Права на материалы

Nunito и Unbounded распространяются по SIL Open Font License 1.1; тексты лицензий в `core/designsystem/fonts`. Пользователь подтвердил права на `core/pet/src/main/assets/models/owl/finny.glb` и шесть текстур совы для включения в прототип. Шесть прозрачных 2D-вариантов совы для узкого экрана созданы из уже включённого портрета совы, включая пять отредактированных цветовых вариантов. Векторная иконка приложения создана в исходниках проекта. Основные программные зависимости и их версии приведены в `gradle/libs.versions.toml`; перечень и ссылки на лицензии — в техническом отчёте. При передаче прав третьим лицам отдельно приложите исходное подтверждение прав на модель, текстуры и исходный портрет.
