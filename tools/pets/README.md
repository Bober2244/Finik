# Finik: оригинальные 3D-питомцы

Три самостоятельные антропоморфные модели: рыжий кот, голубая сова и коричневая собака. Тело каждого персонажа — цельная замкнутая полигональная сетка `PolygonBody`: голова, шея, торс, руки и ноги соединены общими гранями. Контуры морды, ушей, хвоста, аксессуаров и предметов построены из полигонов специально для персонажей; стандартные сферы и капсулы Blender не используются. Все видимые сетки имеют веса костей. Кисти анимированы через запечённое решение двухзвенной IK; IK в приложении не нужна.

## Готовые файлы

- Исходники и прозрачные превью: `/Users/bi_ba/Blender/Finik_models/{cat,owl,dog}.blend`, `{cat,owl,dog}_preview.png`.
- Экспорт для Android: `core/pet/src/main/assets/models/pets/{cat,owl,dog}.glb`.
- Карточки и резервный вид: `core/pet/src/main/res/drawable-nodpi/pet_{cat,owl,dog}.png` (768 × 768, RGBA).
- `manifest.json` рядом с GLB содержит длительности клипов, имена материалов/узлов и точные бюджеты геометрии.

В каждом GLB один skin, 27 костей, восемь mesh nodes и семь анимаций. Размер менее 1 МБ на питомца; точное число полигонов приведено в `manifest.json`. `PolygonBody` остаётся цельной сеткой с петлями вокруг суставов и смешанными весами костей. Черты лица, аксессуары и предметы — отдельные скелетные сетки. Материалы используют стандартные glTF PBR-параметры; текстуры, shader extensions и внешние ресурсы не требуются.

## Контракт приложения

В glTF ось вверх `+Y`, лицо направлено в `+Z`. Начало координат — на полу посередине ступней. Исходная сцена Blender: Z вверх, лицо в −Y. Нормализуйте модель по bounding box, не поворачивайте её дополнительно вокруг вертикальной оси.

| Назначение | Имя |
|---|---|
| Основная шерсть / перья | `FurPrimary` |
| Светлая шерсть / перья | `FurSecondary` |
| Радужная оболочка | `EyeIris` |
| Цвет аксессуара | `Accessory` |
| Шарф | mesh `Accessory_Scarf` |
| Бабочка | mesh `Accessory_Bow` |
| Кепка-берет | mesh `Accessory_Cap` |

Меняйте `baseColorFactor` экземпляров материалов, включая все вхождения материала в разных mesh primitives. Цвет передаётся в линейном RGB. Для переключения аксессуара показывайте ровно один mesh с нужным префиксом; вариант «без аксессуара» скрывает все три. Все варианты экспортированы, а исходная сцена и PNG по умолчанию показывают шарф.

## Анимации

| Клипы | Секунды | Содержание |
|---|---:|---|
| `Idle` | 3.0 | Дыхание, движения головы, ушей и хвоста; зацикливается |
| `Eat` | 3.2 | Поднесение кусочка еды ко рту и жевание |
| `Drink` | 3.6 | Хват бутылки снизу, подъём горлышка ко рту, глотки |
| `Happy` | 2.4 | Приподнятые лапы, лёгкие прыжки, мимика и хвост |
| `Sad` | 3.0 | Поникшая поза, опущенные уши, печальные брови |
| `Play` | 3.6 | Игра с мячом в лапах |
| `Wave` | 2.4 | Приветствие лапой |

Ищите клипы по имени: glTF exporter сортирует их по алфавиту. После одноразовой анимации возвращайтесь к `Idle`. Каждый клип содержит ключи всех костей, поэтому переход с любого действия сбрасывает масштаб неактивных предметов. `PropFood`, `PropBottle`, `PropToy` имеют масштаб `0.001` вне своего действия и `1` внутри; это переносимый способ скрытия, не требующий анимации видимости glTF. Размер пропов в rest pose находится внутри габаритов персонажа.

`Eat` показывает универсальный кусочек-фрукт. Для еды другой формы скрывайте mesh `Prop_Food`, а собственную модель еды присоединяйте к кости `FoodSocket` в правой кисти. Подберите её локальное смещение и масштаб, сохраняя контакт с ртом. Это анимация использования любой подставленной еды, а не библиотека отдельных продуктов.

## Изменение исходников и повторная сборка

Откройте нужный `.blend` в Blender. Armature называется `FinikRig`, все Actions сохранены с fake user и доступны в Action Editor. Аксессуары Bow/Cap скрыты только для исходного превью: включите нужный объект в Outliner. Тело и аксессуары являются scene-root meshes с Armature modifier — связь с костями сохраняется без object parenting.

Полная воспроизводимая сборка (Blender 5.2):

```sh
/Applications/Blender.app/Contents/MacOS/Blender --background --factory-startup --python tools/pets/build_pets.py
```

Скрипт работает в отдельном процессе, не затрагивает открытые сцены Blender и пересоздаёт только перечисленные файлы в каталоге `Finik_models` и соответствующие Android assets. После ручной правки исходников не запускайте генератор до сохранения собственной копии: он намеренно пересоздаёт процедурные модели.

Проверка GLB валидатором Khronos и аудит топологии, весов и движения суставов в исходных `.blend` и экспортированных `.glb`:

```sh
npm --prefix tools/pets install
npm --prefix tools/pets run validate
/Applications/Blender.app/Contents/MacOS/Blender --background --factory-startup --python tools/pets/validate_mesh.py -- /Users/bi_ba/Blender/Finik_models
```

Для наглядной проверки реальных рёбер тела и положения костей:

```sh
/Applications/Blender.app/Contents/MacOS/Blender --background --factory-startup --python tools/pets/render_wireframe.py -- /Users/bi_ba/Blender/Finik_models/cat.blend /Users/bi_ba/Blender/Finik_models/cat_wireframe.png
```

Возрастные статусы приложения используют одну и ту же анатомию и скелет с изменением отображаемого размера. Отдельные анатомические формы детёныша и взрослого здесь не экспортируются.
