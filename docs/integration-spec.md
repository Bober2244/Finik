# Finik: согласованные правила интеграции

Дата: 2026-09-29. Источник: последовательные решения пользователя в чате.
Проекты: Android `Finik` и API `finik-backend`.

## Решения пользователя

1. Питомец из Android: сова, шесть цветов, несколько аксессуаров. Сохраняем мобильное оформление и стадии совы.
2. Первый план пустой; весь недельный доход находится в свободных монетах.
3. Для подтверждения плана не обязательно распределять все монеты.
4. Ручное пополнение цели списывает деньги из статьи SAVE («Копилка») после подтверждения плана.
5. Накопления можно снимать; снятая сумма поступает в бюджет PLAY («Развлечения»).
6. У каждой цели собственные накопления. Переключение цели не переносит деньги между целями.
7. Обычная игра идёт по реальному времени. Период — неделя; вручную завершать день/неделю и пропускать время нельзя. Ускорение доступно только в демо.
8. Неделя календарная: понедельник 00:00 — следующий понедельник 00:00. Первая неделя может быть неполной.
9. Границы дней и недель определяются часовым поясом игрока. Реальное время определяет сервер.
10. В первую неполную неделю выдаётся полный недельный доход.
11. Остатки FOOD/WATER/PLAY в конце недели возвращаются в свободные монеты.
12. Остаток SAVE автоматически поступает в выбранную цель.
13. К автоматически переводимому остатку SAVE добавляется 5%, округлённых вниз до целой монеты. Проценты не начисляются на весь баланс цели.
14. При недостатке FOOD/WATER действие ухода может списать полную стоимость из SAVE, если там достаточно монет; фиксируется перерасход. Для PLAY такой возможности нет.
15. Одно действие ухода даёт +22 к соответствующей потребности и +1 XP.
16. Потребности снижаются ежедневно. В демо также обрабатываются пропущенные дни.
17. При нулевых потребностях снимается XP, возможен откат стадии роста.
18. Прогресс обычных заданий обновляется каждую календарную неделю; награда доступна раз за неделю.
19. Награды за задания всегда поступают в свободные монеты.
20. Подтверждённый план можно пополнять свободными монетами в любую статью. Перекладывать уже распределённые деньги между статьями нельзя.
21. Базовые цены растут по серверной формуле: +5% исходной цены за неделю, предел +50%. Иногда допускаются небольшие снижения цен, сохраняющие общую сложность.
22. Количественные цели заданий растут на 10% исходного значения за неделю, предел ×2; награды растут медленнее по серверной формуле.
23. Изменение недельного дохода применяется со следующей недели; текущий бюджет не пересоздаётся.
24. Бонус +5 монет за каждые семь игровых дней; ежедневное посещение для него не требуется.
25. Ассортимент сервера: 16 товаров, включая косметику и товары из событий; названия и оформление адаптируются под сову.
26. Задания сервера: семь уроков с 21 вопросом, три экспедиции, пять заданий по игровым действиям.
27. Включено повторение тем с учётом ошибок.
28. Включены ежедневные события с реальным влиянием на игровые монеты, потребности, цены и доступность товаров.
29. Включены серверные ИИ-функции: реплики, дневник, план накопления, объяснения ответов, итог недели, чат с совой.
30. Без интернета доступен только просмотр последнего загруженного состояния. Все изменения требуют подключения. Очередь офлайн-действий не нужна.
31. Включён родительский бонус 1–20 монет с причиной и PIN-подтверждением.
32. При возвращении после пропущенных недель начисляется только доход текущей недели, один раз. Доход за пропущенные недели не накапливается.
33. На данном этапе деморежим открыт всем, без кода доступа.
34. Демо использует отдельный профиль. При запуске эксперт выбирает новую игру или подготовленный профиль с прогрессом.
35. Существующих устройств с локальным прогрессом нет: перенос старых сохранений и их резервирование не требуются.

## Принципы реализации

- Сервер — источник состояния и результатов действий. Android не начисляет деньги, опыт и награды параллельно с сервером.
- Room используется как кэш для просмотра без сети.
- Первый вход: авторизация устройства → проверка наличия питомца → создание или загрузка серверной игры → загрузка каталогов.
- Обычная и демонстрационная сессии раздельны. Ускорение времени должно проверяться сервером, а не только скрываться в интерфейсе.
- Дневные/недельные переходы должны быть повторяемы без повторной выдачи дохода или наград и корректно учитывать часовые пояса и неполную первую неделю.
- Не выполнять автоматические повторы финансовых POST-команд без защиты от повторного выполнения.
- Локальные идентификаторы товаров/заданий заменяются серверными; числовые ответы, экспедиции и повторение тем получают поддержку в клиенте.
- В debug разрешается HTTP для локального API; release сохраняет требование HTTPS.
- Локальная база PostgreSQL уже подготовлена на порту 5433. Секреты из `.env` не включаются в документацию или git.

## Детали реализации

- Снижение цен происходит в событии распродажи: скидка ограничена 10%, цена округляется вверх до целой монеты.
- Часовой пояс сохраняется при создании питомца. Сервер применяет прошедшие дни и недели при запросе состояния или действии; отдельный таймер клиента не нужен.
- API возвращает все балансы целей, границы недели, режим и разрешение на ускорение времени. Описание маршрутов находится в README backend и Swagger.
- Для совы используется базовый серверный ежедневный расход потребностей; прежние бонусы видов растений не возвращают отменённые правила ухода.
- Автоматически повторяется только GET после сетевого обрыва, максимум один раз. Изменяющие команды автоматически не повторяются; неиспользуемые соединения закрываются.
- Для экспертизы debug-сборка позволяет менять IP/URL сервера в приложении, проверять соединение и сохранять адрес без пересборки. При смене сервера сессии и кэш обновляются, идентификатор установки сохраняется. В релизе адрес задаётся при сборке и требует HTTPS.
- Существующая авторизация по устройству не означает наличие входа по почте или восстановления аккаунта между устройствами.

## Порядок работ

1. Зафиксировать правила и контракт API.
2. Реализовать календарь, демо, экономику, цели и внешность совы на сервере.
3. Перевести Android на серверное состояние, авторизацию и кэш без офлайн-изменений.
4. Подключить каталоги, задания, экспедиции, повторение, события, ИИ и родительский бонус.
5. Проверить сценарии первого входа, планирования, ухода, покупок, накоплений, смены недели, демо, отсутствия сети и перезапуска.
