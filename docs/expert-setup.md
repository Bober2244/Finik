# Подключение телефона к локальному серверу

В debug-сборке адрес сервера меняется внутри приложения. Один APK подходит для разных компьютеров и Wi-Fi сетей; после смены IP пересобирать его не нужно.

## Подготовить APK

Откройте Android-проект в Android Studio и соберите вариант `debug`, либо выполните в корне проекта:

```sh
./gradlew :app:assembleDebug
```

Файл для установки: `app/build/outputs/apk/debug/app-debug.apk`. Передайте его на Android-телефон и установите. Интернет нужен для первоначальной загрузки зависимостей сборки; работа приложения требует доступного API.

## Запустить сервер на Mac

1. Запустите Postgres.app. В подготовленной локальной среде база `finik` работает на порту **5433**; миграции и справочники уже загружены.
2. В PyCharm откройте `finik-backend` и конфигурацию **Finik API**.
3. В параметрах запуска используйте:

```text
main:app --app-dir src --reload --host 0.0.0.0 --port 8000
```

4. Нажмите Run. `0.0.0.0` — адрес прослушивания: в приложение вводится IP компьютера в Wi-Fi сети.
5. Узнайте IP командой в терминале Mac:

```sh
ipconfig getifaddr en0
```

Например, команда может показать `192.168.1.43`. При переносе сервера на другой компьютер сначала выполните установку, миграции и загрузку справочников по README backend. Docker для запуска через Postgres.app и PyCharm не требуется.

## Подключить приложение

1. Подключите телефон и компьютер к одной Wi-Fi сети.
2. На экране знакомства нажмите **«Адрес сервера»**. Если игра уже создана, откройте **Профиль → Адрес сервера**. При отсутствии связи есть кнопка **«Изменить адрес сервера»**.
3. Введите IP, например `192.168.1.43`. Приложение использует `http://192.168.1.43:8000/`.
4. Если порт другой, укажите его: `192.168.1.43:8001`. Можно вставить полный URL: `http://192.168.1.43:8000/` или HTTPS-адрес.
5. Нажмите **«Проверить и подключиться»**. При успешном подключении приложение сохранит адрес и загрузит профиль с выбранного сервера.
6. Для экспертизы выберите **«Демо для экспертов»**, затем новую игру или готовый профиль.

Адрес сохраняется после закрытия приложения. При ошибке проверки прежний адрес остаётся выбранным. Повторная сборка и ручное редактирование исходников не нужны.

При изменении IP того же сервера прогресс восстанавливается по идентификатору установки. У другого сервера своя база и свой прогресс. Сохранения и токены разных серверов не смешиваются; при смене адреса локальный кэш обновляется с выбранного сервера. Обычный и демонстрационный профили остаются разделены.

## Эмулятор и релиз

- Для Android Emulator в окне настроек есть кнопка **«Эмулятор»**. Она подставляет `http://10.0.2.2:8000/`.
- Настройка адреса доступна в `debug`. Release использует HTTPS-адрес, заданный через `FINIK_API_BASE_URL` при сборке; локальные настройки debug в релизе не применяются.
- `FINIK_DEBUG_API_BASE_URL` по-прежнему задаёт начальный адрес debug-сборки, если нужен заранее настроенный APK.

## Если подключение не работает

Откройте в браузере телефона `http://IP-компьютера:8000/health`. Ответ подтверждает, что телефон видит API.

Если страница не открывается, проверьте запуск API с `--host 0.0.0.0`, актуальный IP, общую Wi-Fi сеть и разрешение входящих соединений Python в брандмауэре macOS. Гостевая сеть или VPN могут ограничивать доступ к компьютеру. PostgreSQL должен работать на компьютере; открывать его порт для телефона не требуется.
