# Проверка интеграции Finik

Дата: 29 сентября 2026 года. Правила: [integration-spec.md](integration-spec.md).

## Результат

Android получает игровое состояние и результаты действий от FastAPI. PostgreSQL хранит прогресс, Room — отдельные кэши обычного и демонстрационного профиля. Без сети доступны просмотр и навигация; игровые изменения заблокированы. Перенос прежних локальных сохранений не добавлялся по решению пользователя.

## Проверка приложения с настоящим API

Использован Android Emulator `Medium_Phone`, Android 36.1, arm64. Эмулятор запущен с `-read-only -no-snapshot-save -no-snapshot-load`, поэтому тестовая установка и её данные не сохранялись в исходный AVD.

Проверено через интерфейс:

1. Авторизация установки, экран знакомства, выбор подготовленного демо.
2. Отображение совы с несколькими аксессуарами, серверного события и календарной границы недели.
3. Уход: вода 85 → 100, расход двух монет из WATER.
4. Пополнение подтверждённого плана: FOOD 12 → 13, свободные монеты 12 → 11; уменьшение статьи недоступно.
5. Вклад пяти монет: SAVE 12 → 7, выбранная цель 35 → 40; другие цели остались отдельными.
6. Остановка API и холодный запуск приложения: сохранённый профиль отображается, есть сообщение об отсутствии связи, кнопки игровых действий отключены.
7. Повторный запуск API и приложения: те же остатки восстановлены, связь работает.
8. Экспедиция загружается после простоя. Числовой бюджет 8/4/8 принят сервером: этап 1 → 2, кошелёк истории 32 → 12, запас 0 → 8.
9. Завершение недели в демо: показан отчёт, SAVE 7 переведён в цель 40 → 47, новый план пустой. Проценты округляются вниз: от семи монет прибавка равна нулю.
10. Выход из демо и создание обычной совы: отдельный профиль, 40 свободных монет, пустой план, срок недели по Europe/Moscow. Кнопок пропуска времени в обычной игре нет.

HTTP-проверки дополнительно подтвердили ответы API для витрины, заданий, истории, профиля, достижений, словаря, события, повторения тем и заготовок ИИ.

## Как запустить снова

1. Запустить PostgreSQL в Postgres.app на порту **5433**.
2. Открыть `/Users/bi_ba/PycharmProjects/finik-backend` в PyCharm. Выбрать интерпретатор `.venv/bin/python` и конфигурацию **Finik API**, нажать Run.
3. Открыть [Swagger](http://127.0.0.1:8000/docs).
4. Запустить Android из Android Studio на эмуляторе. В **«Адрес сервера»** нажать **«Эмулятор»**, затем **«Проверить и подключиться»**: будет выбран `http://10.0.2.2:8000/`.

Миграция и справочники в локальной `finik` уже обновлены. Docker для этого варианта не требуется. Альтернативный запуск через Docker описан в README backend; `.dockerignore` исключает локальное окружение и секреты из образа, но Docker-сборка в этой проверке не запускалась.

Для физического телефона нужен доступный ему адрес компьютера и запуск API с `--host 0.0.0.0`. В debug адрес теперь задаётся внутри приложения через **«Адрес сервера»**; переменная `FINIK_DEBUG_API_BASE_URL` задаёт только начальное значение. Release требует HTTPS и `FINIK_API_BASE_URL`. Подробности: [инструкция эксперта](expert-setup.md).

APK: `app/build/outputs/apk/debug/app-debug.apk` в Android-проекте. После проверки временный сервер и эмулятор остановлены, PostgreSQL оставлен работающим.

## Проверка настройки адреса сервера

Дополнительно 29 сентября проверена смена адреса без пересборки APK:

- Debug APK запущен с намеренно недоступным начальным адресом. Кнопка настройки доступна на экране знакомства и в сообщении об отсутствии связи.
- Введён `192.168.1.43:8001`; приложение проверило API и подключилось к отдельному тестовому серверу с копией БД.
- Создан подготовленный демопрофиль и выполнен уход: вода 85 → 100, остаток WATER 10 → 8.
- Из профиля введён недоступный порт 65534: показана ошибка, прежний адрес и профиль сохранены.
- Проверена ошибка некорректного порта; ошибочный адрес не сохранён.
- Через настройки профиля адрес изменён на `10.0.2.2:8001` того же тестового API. Демо продолжилось, повторного создания подготовленного сценария не произошло.
- После принудительного закрытия и холодного запуска выбранный адрес сохранён, вода осталась 100, остаток WATER — 8, свободные монеты — 12.
- Диалог визуально проверен на эмуляторе. Пользовательский телефон не использовался для установки; работающий пользовательский API на порту 8000 не останавливался. Временный тестовый API на 8001 и эмулятор остановлены после проверки.

Автоматические тесты дополнительно проверили отсутствие старого токена на новом сервере, очистку обоих кэшей при смене адреса, сохранение подключения при ошибке авторизации, сохранение идентификатора установки, продолжение переключения при закрытии экрана и игнорирование пользовательского адреса в release. Итоговый debug APK собран с текущим начальным адресом из проекта `http://192.168.1.43:8000/`; его можно изменить в приложении. Пользовательское изменение начального адреса в `app/build.gradle.kts` сохранено.

- Ключи GigaChat/DeepSeek в текущей среде не заданы: проверены подготовленные ответы, живые ответы провайдера не проверялись.
- Подписанный релиз, физический телефон и развёртывание внешнего HTTPS-сервера не проверялись. Архивный конкурсный APK содержит предыдущую локальную версию.
- Авторизация остаётся привязанной к установке приложения; вход по почте и восстановление аккаунта на другом устройстве не добавлялись. Родительский PIN задаётся на сервере.
- Все уроки и концовки экспедиций вручную не проходились; их API и правила покрыты автоматическими тестами.
